# Zenvori

Zenvori is an anime discovery website built with HTML, CSS, JavaScript, Node.js, and Express.

## Features

- Anime discovery and search
- Genre filtering and sorting
- Anime posters and details
- Responsive website pages
- Anime data retrieved from the AniList API

## Requirements

- Node.js and npm
- Internet connection for anime data
- Access to the AniList API, subject to its terms

## Installation

1. Install Node.js and npm.
2. Download or clone this project.
3. Open a terminal in the project folder.
4. Install dependencies:

   npm install

5. Start the website:

   npm start

6. Open http://localhost:3000 in your browser.

## Project Structure

- server.js — Express server
- public/index.html — Homepage
- public/styles.css — Homepage styles
- public/app.js — Homepage functionality
- public/anime.html — Anime details page
- public/anime.css — Anime details styles
- public/anime.js — Anime details functionality
- public/discover.html — Anime discovery page
- public/discover.css — Discovery page styles
- public/discover.js — Discovery functionality
